cmdesk

An autonomous AI helpdesk agent that handles tickets across email, web, WhatsApp, and your favorite platforms — powered by local LLMs.

Admin Dashboard Widget Preview GitHub

Features

Everything you need to run a modern AI-powered helpdesk.

📧

Multi-Platform Ticketing

Email, web widgets, WhatsApp, osTicket, Freshdesk, Zammad — unify all channels into one queue.

🤖

AI Auto-Response

GPT or local LLM (llama.cpp) powered intelligent responses with context-aware suggestions.

📊

Cost Tracking

Monitor AI API usage costs per ticket, per agent, and per session in real time.

⏱

SLA Management

Define and monitor service level agreements with automatic escalation workflows.

🔬

Knowledge Base

Built-in vector search (ChromaDB) for instant retrieval of solutions from your KB.

💻

Agent Dashboard

Real-time ticket queue, performance metrics, audit logs, and session management.

🕒

Workflow Automation

n8n-powered workflows for ticket routing, escalation, surveys, and daily digests.

🔒

Rate Limiting

Per-session rate limits with automatic blocking and audit logging for abuse prevention.

Architecture

How the pieces fit together.

▶ User → [ WhatsApp / Web Widget / Email / API ]
└ → Helpdesk Agent → LLM (llama.cpp / OpenAI)
└ → ChromaDB • SearXNG (context retrieval)
└ → Ticket Platform (osTicket / Freshdesk / Zammad / Email)
└ → n8n Workflows (routing, escalation, surveys)

▶ Admin → Admin Dashboard → PostgreSQL + Redis
→ Metrics • Costs • Audit Log

# All services containerized — one docker compose up

Quick Start

Get cmdesk running in minutes.

$ git clone https://github.com/OneByJorah/cmdesk.git
$ cd cmdesk
$ cp .env.example .env # Configure AI & email
$ docker compose up -d # Launch everything

▶ Dashboard http://localhost:8000
▶ Admin http://localhost:8000/admin
▶ Agent API http://localhost:8080
